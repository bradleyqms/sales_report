# Documentation Structure

This folder contains documentation organized by ticket/topic.

## Folders

- **regional-mapping-research/** — Technical documentation for regional mapping implementation
  - [INDEX.md](regional-mapping-research/INDEX.md) — Navigation guide and overview
  - Supporting research documents covering data flow, mappings, architecture, and implementation guidance
  - See `.ai/features/DNR-5-regional-mapping-research/` for ticket-specific research

## Adding Documentation

When adding new documentation:
1. Create a folder with a **ticket-agnostic name** (e.g., `feature-name/`, `regional-mapping-research/`)
2. Create an `INDEX.md` that lists all documents and their purposes
3. Place all supporting technical documentation `.md` files in that folder
4. Place main ticket research in `.ai/features/{TICKET_NUMBER}-description/`
5. Update this README with the new folder information

## Archive

Completed and archived research documentation may be moved to an `archive/` subfolder.
